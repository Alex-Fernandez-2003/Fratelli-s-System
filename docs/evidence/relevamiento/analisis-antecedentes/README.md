# Método 2 — Análisis de antecedentes

## 1. Técnica

**Análisis de antecedentes**, utilizado metodológicamente como una forma de **análisis documental**.

```text
analisis-antecedentes.md
detalle-de-la-manera-de-trabajo.pdf
```

`analisis-antecedentes.md` contiene el análisis elaborado por el equipo y el PDF se conserva como fuente primaria.

Documento redactado por **Ana Paola Viscarra Chambi** antes de la primera entrevista formal.

## 3. Objetivo

Obtener una descripción inicial y estructurada del funcionamiento de Fratelli para:

- reconocer actores y responsabilidades;
- comprender pedidos, comandas y cocina;
- identificar producción e inventario;
- conocer compras, proveedores y clientes;
- reconocer planillas, pagos y cierres;
- detectar procesos que todavía dependen de registros manuales o externos;
- preparar preguntas para las entrevistas posteriores.

## 4. Aportes principales

El antecedente documenta, entre otros puntos:

- aproximadamente nueve trabajadores;
- cuatro meseros con funciones de atención, caja, bebidas y barismo;
- pedidos que generan comandas para cocina;
- días de producción;
- control de inventario y movimientos;
- ausencia de alerta automática de stock mínimo;
- aproximadamente veinte proveedores;
- compras parcialmente externas al sistema;
- clientes y ventas a crédito en el sistema existente;
- planillas para información laboral;
- cierres de caja;
- coexistencia del sistema actual con procesos manuales.

## 5. Limitación

El documento describe el funcionamiento general, pero por sí solo no define con precisión todas las reglas, excepciones, estados, permisos o cálculos requeridos por el nuevo sistema.

Por esa razón se contrasta con las entrevistas y con el análisis de sistemas similares.
