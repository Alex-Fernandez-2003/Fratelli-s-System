# Método 1 — Entrevistas semiestructuradas

## 1. Técnica

El proyecto utiliza **entrevista semiestructurada** como una de sus tres técnicas de relevamiento.

Se realizaron dos sesiones. Aunque sus objetivos son diferentes, ambas pertenecen al **mismo método**.

## 2. Sesiones

### ENT-01 — Diagnóstico general

Ubicación:

```text
entrevista-01-trabajadora/
```

Finalidad:

- validar y ampliar el antecedente documental;
- identificar problemas prioritarios;
- comprender inventario, compras, asistencia, gastos, producción y sistema actual;
- confirmar la intención de reemplazo del sistema.

### ENT-02 — Refinamiento de reglas operativas

Ubicación:

```text
entrevista-02-trabajadora/
```

Finalidad:

- aclarar unidades y conversiones;
- precisar producción y mermas;
- definir responsabilidades de compra y recepción;
- comprender la relación entre los dos turnos;
- precisar monto de inicio, traspaso y cierre de caja;
- resolver los bloqueos documentales de `HU-004`, `HU-007`, `HU-017`, `HU-025`, `HU-026` y `HU-027`.

## 3. Regla de evidencia

El audio es la fuente primaria de cada sesión. La transcripción facilita el análisis. Ante una ambigüedad que no pueda resolverse a partir de la grabación, el dato debe mantenerse como pendiente o validarse mediante la Product Owner.
