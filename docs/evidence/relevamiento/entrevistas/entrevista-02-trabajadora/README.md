## Finalidad

La entrevista se realizó para refinar reglas que mantenían historias del MVP en estado `REFINAMIENTO REQUERIDO`, especialmente:

```text
HU-004
HU-007
HU-017
HU-025
HU-026
HU-027
```

Los temas cubiertos fueron:

- unidades y conversiones;
- cantidad final de producción;
- mermas/bajas y motivos;
- necesidad de separar o no producciones/lotes;
- datos de trazabilidad de producción;
- vencimiento de preparados;
- responsabilidades de compra;
- respaldo mediante recibos;
- recepción y verificación de compras;
- compras incompletas;
- funcionamiento de los dos turnos;
- monto inicial;
- traspaso entre turnos;
- cierre único de caja;
- gastos/caja chica;
- diferencias de efectivo;
- tratamiento separado de PedidosYa;
- responsable del cierre y revisión por contabilidad;
- personas con múltiples responsabilidades operativas.

## Resultado documental

Las respuestas proporcionan información suficiente para retirar los **bloqueos críticos** de las seis historias anteriores y devolverlas a `Backlog` como `CANDIDATA A READY`.

Esto **no significa** que las historias ya cumplan la Definition of Ready. La revisión formal de DoR se realizará posteriormente.
