# Sistema de restaurante — Fratelli

Sprint 1 integra autenticación, usuarios, catálogo, proveedores, inventario, pedidos, cocina, gastos y asistencia. `develop` es la rama de integración. La aplicación autenticada usa un único shell con sidebar desktop y drawer mobile, y sus rutas y acciones se filtran por la unión de roles. Consulte `backend/README.md` y `frontend/README.md` para la configuración; el frontend usa pnpm y su `pnpm-lock.yaml` como referencia canónica.

Los artefactos de cambios de OpenSpec son canónicos bajo `docs/openspec/`. La unión de compatibilidad local del runtime de Windows se documenta en `docs/openspec/README.md`.

## Idioma de la documentación

Salvo identificadores técnicos, nombres propios, código y comandos, la documentación del repositorio está en español.
