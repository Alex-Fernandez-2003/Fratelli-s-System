# Sistema de restaurante — Fratelli

Sprint 0 proporciona únicamente infraestructura técnica; no implementa HUs. `main` es estable y `develop` es la rama de integración. Use ramas cortas en kebab-case con los prefijos `feature/`, `fix/`, `docs/` o `chore/` y PRs; no haga push directamente a main. Los commits usan `type: short description` (`feat`, `fix`, `docs`, `chore`, `refactor`, `test`); el ID de una HU es opcional. Consulte `backend/README.md` y `frontend/README.md` para la configuración; el frontend usa pnpm y su `pnpm-lock.yaml` como referencia canónica.

Los artefactos de cambios de OpenSpec son canónicos bajo `docs/openspec/`. La unión de compatibilidad local del runtime de Windows se documenta en `docs/openspec/README.md`.

## Idioma de la documentación

Salvo identificadores técnicos, nombres propios, código y comandos, la documentación del repositorio está en español.
